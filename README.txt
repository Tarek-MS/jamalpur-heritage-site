【কীভাবে চালাবেন】
  ১. index.html ফাইলটি ডাবল ক্লিক করুন — ব্রাউজারে (Chrome/Firefox)
     ওয়েবসাইট খুলে যাবে। আলাদা কোনো সফটওয়্যার বা ইন্টারনেট লাগে না।
  ২. বাংলা ফন্ট (Hind Siliguri / Noto Serif Bengali) ইন্টারনেট
     থাকলে সুন্দর দেখাবে; না থাকলেও সাইট কাজ করবে।

【ফাইল তালিকা】
  index.html  → পেজের কাঠামো (কী কী থাকবে)
  style.css   → ডিজাইন (রঙ, সাইজ, সাজসজ্জা)
  script.js   → সব কাজ (পণ্য দেখানো, অর্ডার, রসিদ, অ্যাডমিন)
  images/     → পণ্যের সব ছবি
  README.txt  → এই নির্দেশনা

【কী কী আছে】
  • ১৬টি পণ্য — নাম, প্রচলিত নাম, ঐতিহ্যের গল্প, উপকরণ
  • ক্যাটাগরি ফিল্টার: খাদ্য / হস্তশিল্প / প্রসেশনি
  • পণ্যে ক্লিক করলে বিস্তারিত পপআপ (একাধিক ছবির গ্যালারিসহ)
  • অর্ডার ফর্ম → অর্ডার রসিদ (প্রিন্ট / PDF সেভ / ডাউনলোড)
  • রসিদ হোয়াটসঅ্যাপে (01304542204) পাঠানোর ব্যবস্থা
  • ফুটারে "অ্যাডমিন" → কোড 591990 দিলে এডিট প্যানেল (পণ্য/ছবি/লেখা/ফোন বদল, প্রকাশ) + অর্ডার টেবিল

【অর্ডার কীভাবে জমা থাকে — গুরুত্বপূর্ণ】
  এটি একটি সাধারণ সাইট (সার্ভার নেই), তাই অর্ডার জমা হয় দুইভাবে:
  ১) রসিদ: কাস্টমার রসিদ প্রিন্ট/PDF/ডাউনলোড করে রাখতে পারে এবং
     এক ক্লিকে অর্ডারের পুরো হিসাব আপনার হোয়াটসঅ্যাপে পাঠাতে পারে।
     এটিই দোকানদার হিসেবে অর্ডার পাওয়ার প্রধান উপায়।
  ২) localStorage: যে ব্রাউজারে অর্ডার হয়, সেই ডিভাইসেই জমা থাকে।
     তাই নিজের ডিভাইসে টেস্ট করে "অ্যাডমিন" প্যানেলে দেখতে পারবেন।
     কাস্টমারের ডিভাইসে জমানো অর্ডার আপনি সরাসরি দেখতে পাবেন না —
     সেটি পেতে হোয়াটসঅ্যাপ বাটনই আসল।

【পণ্যের দাম/লেখা বদলাতে চাইলে】
  script.js খুলে PRODUCTS অংশে দেখুন — প্রতিটি পণ্যের নিচে
  price: ২০০ (দাম), unit: "প্রতি প্লেট" (একক) ইত্যাদি আছে।
  নতুন ছবি দিতে চাইলে images ফোল্ডারে ছবি রেখে ফাইলের নাম
  image: "images/..." এ বদলে দিন।

【দোকানের তথ্য বদলাতে চাইলে】
  script.js-এর শুরুতে SITE অংশে ফোন নম্বর, ঠিকানা ইত্যাদি আছে।
  অ্যাডমিন কোড বদলাতে adminPin: "591990" বদলান।

【গুগল ফর্ম (ঐচ্ছিক)】
  আপনার গুগল ফর্মটি এখন সাইন-ইন ছাড়া খোলে না, তাই বন্ধ আছে।
  ফর্মটি "যে কেউ" খুললে script.js-এর GOOGLE_FORM অংশে
  enabled: true করে entry ID বসালে অর্ডার গুগল শিটেও জমা হবে।
  ধাপে ধাপে নির্দেশনা script.js-এর ১৩ নম্বর অংশে আছে।


【অর্ডার বাটন → গুগল ফর্ম】
  সব "অর্ডার করুন" বাটন এখন গুগল ফর্মে (নতুন ট্যাবে) নিয়ে যায়।
  লিংক বদলাতে script.js-এর ORDER_FORM_URL বদলান।


【নিজে এডিট ও ছবি আপলোড — editor.js】
  ১) ওয়েবসাইটের নিচে "অ্যাডমিন" চাপুন → কোড 591990
  ২) "পণ্য" ট্যাবে নতুন পণ্য যোগ / এডিট / ছবি বদল / মুছে ফেলা
     "পেজের লেখা ও ছবি" ট্যাবে হিরো ছবি ও লেখা, "যোগাযোগ" ট্যাবে ফোন-ঠিকানা-ফর্ম লিংক
  ৩) "প্রকাশ করুন" ট্যাবে GitHub তথ্য দিয়ে বাটন চাপুন — সবার জন্য সাইট আপডেট হবে

  GitHub টোকেন বানানোর নিয়ম (একবারই):
    GitHub → Settings → Developer settings → Personal access tokens →
    Fine-grained tokens → Generate new token
    • Repository access: Only select repositories → আপনার সাইটের রিপো
    • Permissions → Repository permissions → Contents: Read and write
    • তৈরি হলে টোকেন (github_pat_...) কপি করে প্রকাশ ট্যাবে বসান

  দ্রষ্টব্য: কোডটি script.js-এ লেখা, তাই কেউ সোর্স দেখলে কোড জানতে পারবে —
  কিন্তু GitHub টোকেন ছাড়া কেউ সাইটে কিছু প্রকাশ করতে পারবে না।
  প্রকাশিত কনটেন্ট থাকে data/content.json ও images/uploads/ ফোল্ডারে।


【গুগল ফর্ম এখন পপআপের ভেতরে】
  ক্রেতা নাম/মোবাইল/ঠিকানা দেওয়ার পর গুগল ফর্ম পপআপের ভেতরেই খোলে।
  ফর্ম জমা দিয়ে "রসিদ নিন" চাপলে রসিদ আসে ও অর্ডার তালিকায় জমা হয়।
  লিংক বদলাতে অ্যাডমিন > যোগাযোগ ট্যাব বা script.js-এর SITE.orderForm।
