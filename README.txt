【কীভাবে চালাবেন】
  ১. index.html ফাইলটি ডাবল ক্লিক করুন — ব্রাউজারে (Chrome/Firefox)
     ওয়েবসাইট খুলে যাবে। আলাদা কোনো সফটওয়্যার বা ইন্টারনেট লাগে না।
  ২. বাংলা ফন্ট (Hind Siliguri / Noto Serif Bengali) ইন্টারনেট
     থাকলে সুন্দর দেখাবে; না থাকলেও সাইট কাজ করবে।

【ফাইল তালিকা】
  index.html  → পেজের কাঠামো (কী কী থাকবে)
  style.css   → ডিজাইন (রঙ, সাইজ, সাজসজ্জা)
  script.js   → সব কাজ (পণ্য দেখানো, প্রি-অর্ডার, আগ্রহ, রসিদ, অ্যাডমিন)
  images/     → পণ্যের সব ছবি
  README.txt  → এই নির্দেশনা

【কী কী আছে】
  • ১৬টি পণ্য — নাম, প্রচলিত নাম, ঐতিহ্যের গল্প, উপকরণ
  • ★ কোথাও কোনো দাম/মূল্য দেখানো হয় না
  • ক্যাটাগরি ফিল্টার: খাদ্য / হস্তশিল্প / প্রক্রিয়াজাত
  • পণ্যে ক্লিক করলে বিস্তারিত পপআপ (একাধিক ছবির গ্যালারিসহ — দাম নেই)
  • প্রতিটি পণ্যের নিচে ৩টি বাটন:
      ১) বিস্তারিত    → পণ্যের গল্প ও উপকরণ (দামের অংশ নেই)
      ২) প্রি-অর্ডার  → "প্রি অর্ডার করতে চাইলে সরাসরি ০১৩০৪৫৪২২০৪
                       এই নাম্বারে যোগাযোগ করুন।" + ফোন/হোয়াটসঅ্যাপ বাটন
                       + গুগল ফর্ম (ওয়েবসাইটের বাইরে নতুন ট্যাবে খোলে)
      ৩) ইন্টারেস্টেড → আগ্রহ জানানোর ফর্ম: নাম, মোবাইল,
                       ছাত্র আইডি (Student ID — বাধ্যতামূলক),
                       কাঙ্ক্ষিত পরিমাণ → আগ্রহের রসিদ তৈরি হয়
  • রসিদ "ছবি হিসেবে ডাউনলোড" বাটনে PNG ছবি হয়ে সেভ হয়
  • রসিদের ছবি হোয়াটসঅ্যাপে (01304542204) পাঠানোর ব্যবস্থা:
    আগে ছবি ডাউনলোড করুন → "হোয়াটসঅ্যাপে পাঠান" চাপুন →
    মেসেজের সাথে ছবিটি সংযুক্ত (attach) করে পাঠান
  • ফুটারে "অ্যাডমিন" → পিন 1789 দিলে আগ্রহীদের তালিকা + CSV ডাউনলোড

【আগ্রহ কীভাবে জমা থাকে — গুরুত্বপূর্ণ】
  এটি একটি সাধারণ সাইট (সার্ভার নেই), তাই আগ্রহ জমা হয় দুইভাবে:
  ১) রসিদ: কাস্টমার রসিদের ছবি ডাউনলোড করে আপনার হোয়াটসঅ্যাপে
     পাঠায় — এটিই আগ্রহ পাওয়ার প্রধান উপায়।
  ২) localStorage: যে ব্রাউজারে ফর্ম জমা হয়, সেই ডিভাইসেই তালিকা
     থাকে। নিজের ডিভাইসে টেস্ট করে "অ্যাডমিন" প্যানেলে দেখতে পারবেন।

【পণ্যের লেখা বদলাতে চাইলে】
  script.js খুলে PRODUCTS অংশে দেখুন — প্রতিটি পণ্যের নাম, unit
  (একক), history (গল্প), ingredients (উপকরণ) আছে।
  নতুন ছবি দিতে চাইলে images ফোল্ডারে ছবি রেখে ফাইলের নাম
  image: "images/..." এ বদলে দিন।
